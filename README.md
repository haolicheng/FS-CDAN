# FS-CDAN / STDANN 精简源码

本目录从 `experiments` 中抽取了 FS-CDAN（原工程中命名为 STDANN）的必要代码，目标是作为论文复现的精简版本。它保留核心思想：

- 三分支时空残差网络：分别建模邻近性、周期性和趋势性。
- 异构特征融合：在网格尺度上对邻近性、周期性、趋势性和辅助环境特征进行空间自适应加权融合。
- 少样本监督域对抗训练：同时使用源域标签、目标域少量标签和域判别损失。
- 梯度反转层：通过对抗训练学习跨城市共享表征。

## 与论文模型的一致性

本精简版按论文中的 FS-CDAN 主体结构整理：

1. 三分支 ST-ResNet 分别提取邻近性、周期性和趋势性特征。
2. HFFM 将三类时空特征与辅助环境特征映射到同一通道维度，并生成网格尺度的空间注意力权重。
3. 任务预测头输出目标网格的犯罪风险 logits。
4. 域判别器通过梯度反转层进行源域/目标域对抗训练。
5. 训练损失由源域监督损失、目标域少样本监督损失和域判别损失组成。

## 文件说明

- `model.py`：FS-CDAN / STDANN 模型主体。
- `data.py`：张量数据集和 DataLoader 构造。
- `train.py`：少样本监督域对抗训练和评估。
- `run_example.py`：本地接入模板。
- `requirements.txt`：最小依赖。

## 快速使用

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 准备已预处理的源域和目标域张量，并在本地脚本中传入模型结构参数、优化器和训练参数。
